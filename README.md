# 今天吃什麼 — Tiny River Meal Companion

一個只給兩個人使用的選餐原型。沒有想法時，從內建食物庫提供三個不同方向的選擇；選定後可以拍下餐食、留下評價，逐漸形成兩人的吃飯記憶。

## 已完成

- 120 個以上的內建餐食選擇
- 依心情、預算和排除菜系篩選
- 每次提供三個不同菜系的建議
- 避開近期吃過的餐食
- 換一批與選定餐食
- 照片、評價和一句話記錄
- 本機持久化保存
- Tiny River 式克制、安靜、留白的視覺

## 執行

用 Xcode 開啟 `Package.swift`，選擇 iPhone 模擬器後執行。最低系統版本為 iOS 17。

- 推播通知與「讓你替我選」
- 依時間、天氣與位置調整建議
- 餐廳與外賣平台連結
